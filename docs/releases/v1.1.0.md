# Crystal Live Panel v1.1.0

## 中文

本版更新中文直播界面、城都／关都徽章和地图定位，并重做直播布局。

- **中文界面：**控制面板和直播层使用简体中文，覆盖地名、徽章、等级、连接状态与诊断标题。
- **16 枚徽章：**分别读取城都与关都八枚徽章，按所在区域切换徽章栏，显示当前区域及两地合计进度；修正城都钢铁／打击徽章标志位对应关系。
- **地图定位：**为全部 388 张地图建立独立地标映射；两地 46 条道路支持直路、弯道、岔路和 10 号道路南北分图的相对位置移动。
- **直播布局：**新增紫蓝夜景背景与独立信息卡片，队伍采用 3 列 × 2 行布局；游戏窗口精确匹配 GBC 原生画面的六倍缩放。
- **文档与发布：**提供完整中英文 README、界面预览及故障速查；发布流程增加 UDP 测试、包内容检查和 SHA-256 校验文件。

### 下载与升级

- `Crystal-Live-Panel-1.1.0-x64.exe`：Windows 10/11 x64 安装程序。
- `Crystal-Live-Panel-1.1.0-x64.zip`：完整解压后运行的免安装版。
- `SHA256SUMS.txt`：上述两个文件的 SHA-256 校验值。

**从 v1.0.4 升级必须更新 OBS 游戏捕获源的变换：**位置设为 **X=64、Y=112**，尺寸设为 **960 × 864**，裁切到实际游戏内容后对齐。浏览器源仍为 `http://127.0.0.1:17654/overlay`，尺寸仍为 **1536 × 1024**。刷新浏览器源缓存后再检查合成画面。配置与本地精灵缓存通常保留。

使用 PowerShell 计算下载文件的校验值，并与 `SHA256SUMS.txt` 比较：

```powershell
Get-FileHash .\Crystal-Live-Panel-1.1.0-x64.zip -Algorithm SHA256
```

### 兼容与验证范围

仍只支持 TGB Dual 普通单游戏模式及 CRC32 为 `9AB996C9`、SHA-256 为 `65701F63CFB8BCF88A56A6930236E659FC01FEC22BFAD0BE8BB49C739ADA406C` 的指定 ROM。ROM、存档、BIOS 和运行时提取的宝可梦精灵图不随包提供。地图为区域示意图，不是逐格地形。界面使用中文；玩家姓名字符表仍限英文、数字与少量标点。

自动化验证包括单元测试、本机 UDP 集成测试、构建和 ASAR 内容检查。浏览器检查覆盖透明窗口、地图、徽章及连接状态；真实 RetroArch＋OBS 合成效果仍需在使用者的 Windows 直播环境中确认。程序未使用商业代码签名证书。

## English

This release introduces a Simplified Chinese interface, badges for both regions, improved map positioning, and a redesigned stream layout.

- **Chinese interface:** localized place names, badges, levels, connection states, and diagnostic titles throughout the control panel and overlay.
- **All 16 badges:** separate Johto and Kanto flags, automatic regional badge switching, regional and combined totals, and corrected Mineral/Storm flag mapping.
- **Map positioning:** individual landmark mappings for all 388 maps and relative movement along 46 routes, including bends, branches, and both sections of Route 10.
- **Stream layout:** purple night scenery, separate sidebar cards, a three-column/two-row party grid, and an exact 6× native GBC game viewport.
- **Documentation and packaging:** Chinese and English READMEs, previews, troubleshooting, UDP integration tests, packaged-content auditing, and SHA-256 checksums.

### Downloads and upgrade

Choose the `.exe` installer or fully extract the `.zip` portable package for Windows 10/11 x64. Verify either download against `SHA256SUMS.txt`.

**When upgrading from v1.0.4, update the OBS game capture transform:** set its position to **X=64, Y=112** and dimensions to **960 × 864**, after cropping to the actual game content. The browser source remains `http://127.0.0.1:17654/overlay` at **1536 × 1024**. Refresh its cache and check alignment before streaming. Settings and the local sprite cache are normally retained.

Compatibility remains limited to TGB Dual in ordinary single-game mode and the exact ROM hashes listed above. No ROM, save, BIOS, or runtime-extracted Pokémon sprites are bundled. Regional maps are schematics, and Chinese player names remain unsupported. The application UI uses Simplified Chinese.

Automated checks cover unit tests, local UDP integration, builds, and packaged content. Browser checks cover transparency, maps, badges, and connection states; verify actual RetroArch/OBS composition in your Windows streaming environment. Binaries have no commercial code-signing certificate.
