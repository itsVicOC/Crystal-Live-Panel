# README preview images / README 预览图

`overlay-preview.png` and `control-preview.png` show the v1.1.0 interface. They use synthetic trainer data and an empty party, with no real save data or extracted Pokémon sprites.

两张预览图展示 v1.1.0 界面，使用示例训练师数据和空队伍，不含真实存档数据或从 ROM 提取的宝可梦精灵图。

- The purple night landscape is an AI-generated decorative background. The checkerboard and game-area label illustrate the transparent game viewport; they are not part of the runtime overlay.
- Johto badge shapes reproduce the original trainer-card pixels from [pret/pokecrystal, revision 3bc8daa](https://github.com/pret/pokecrystal/blob/3bc8daa4173e96a7f4011dad3922eb6fa5dad5c6/gfx/trainer_card/badges.png). The active palette follows `PREDEFPAL_CGB_BADGE` in [the same revision](https://github.com/pret/pokecrystal/blob/3bc8daa4173e96a7f4011dad3922eb6fa5dad5c6/gfx/sgb/predef.pal).
- Regional map metadata is derived from [pret/pokecrystal](https://github.com/pret/pokecrystal). The map in the preview is a schematic, not a full terrain map.
